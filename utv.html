Machine vision + individual nozzle control on a John Deere UTV

Equipped a John Deere Gator UTV with a spray implement fitted with Pentair Hypro ProStop-E electric nozzle bodies for individual nozzle on/off control, driven by a machine vision camera. A color-segmentation model detects orange targets on the ground.

Built the bridge between the machine vision system and the implement: C++ firmware converts each machine vision detection into ISOBUS (CAN) messages that the ProStop-E implement controller executes on the matching nozzle.

Field tests validated the vision-to-ProStop-E communication chain and measured how travel speed affects detection-to-spray latency.
